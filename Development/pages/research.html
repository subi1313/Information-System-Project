Reference Used in Entire Website: Footer

Footer: The footer of the website is referenced from a learning platform called GFC Global. The minimalist design of footer made it more appealing to use it in the project. The 3 columns in footer is kept in 3 divs. These 3 divs are enclosed in one div called footer. 'display: flex' property of CSS is used in footer div to make the alignment in row. Like footer div, footcont div is created. In which socialmedia div containing image of facebook and instagram which can direct link to respective page and mode div containing button to change background color of webpage is made.

Reference Used in Product Description Page

Product Detail: Product description is referenced from chrono24 watch store. The basic info table's layout of chrono24 website is taken referenced and the more info table in the project is created. 'productdetail' div consists 'info' div and 'description' div for proper layout of more info and description using CSS property 'display: flex'. Table 'tableinfo' uses it's tr, td attributes for displaying watch's short informations. The whole explore more is content of 'detail' section.

Product Recommendation: Watches you may be interested section in the project in is referenced from chrono24 website's you may be interensted in these watches section. The layout of 4 images in a row is kept with reference to it. Each image and text is enclosed in a anchor tag which is enclosed in element div. 'element' divs is enclosed in 'watches' div which uses CSS property 'display: flex' for it's arrangement on row. The whole recommendation block is a part of 'recommendation' section.

Product Review: Product Review is referenced from Titan, a watch selling store's webpage. Three rows i.e. Summary, Customer Reviews and Write a review are enclosed in a div. The div uses CSS property 'display: flex' for it's arrangement on row. Customer reviews of 5 different stars are displayed with the use of 5 different table. Different table is used for making difference in width of td. Write a reciew used button.

Reference Used in
Blog Page

Navigation Bar : In the project, navigating bar is made with the reference of content bar in wikipedia. Each content of blog has it's unique id for navigating bar and same class 'blog-post' which is used for common CSS. Unordered list is used for listing the topics in blog's sidebar which has anchor tag in it. The anchor tag's attribute href uses '#idName' for linking to the particular ID. The list of title's of navigation header is enclosed in 'sidebar' div.
